# React Practice Submission

This project contains all four practices from the provided practice sheet.

## Practices

1. Counter App - useState
2. Student Profile - useRef
3. Student Portal - React Router
4. Task Manager - useState + useRef + React Router

## How to run

Open the project folder in a terminal and run:

npm install

Then:

npm run dev

Open the local address shown by Vite in the browser.

## Checklist

- Application runs without errors.
- useState is used for the counter and task data.
- useRef is used for focusing inputs.
- React Router is used for navigation.
- Buttons work correctly.
- Navigation works without reloading the application.
- The interface is simple and easy to understand.
